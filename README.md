

Obsidian Partner is a modular plugin of Obsidian that gives control over various aspects over workflow. 

## Snippets & Calls 
Useful for creating inline code calls within notes, especially for inline buttons and other repeatable, but quickly accessible codes.
Currently, snippets are .js code notes in a specified folder that can be called upon via an inline backtick phrase. 
Phrasing starts with the backtick, and "partner", and then uses hyphens between each word, with btn representing a button, vw is a view. So, for instance "`partner-btn-pm-modal`" is what I use to trigger the code in my snippets folder which pushes a hidden command that opens the task manager of a project ( in Project Manager Plugin ) based upon a property in the project page the button is located on.
Note: Views are a placeholder as of now, and will be expanded upon concurrently to other coming advancements. 
To use a call, tie a snippet to a phrase when you add the call in the settings pane. Then, use backticks and the given phrase to call the snippet inline on your note.
